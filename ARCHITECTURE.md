# Thuban Desk — architecture contract

Native macOS app (SwiftUI, macOS 15+, Xcode 26, Swift 5 language mode, XcodeGen, ad-hoc signing): Google Calendar
and Gmail for several Google accounts, in Thuban's calm style. Sibling of Thuban Canvas / Thuban Study (same theme
engine, components and Atlas color schemes, Brass default). Design artboards (reproduce closely):
`~/.claude/jobs/bd9882f5/tmp/design/desk/project/*.dc.html` — Main (Calendar week), Month, EventEditor,
RecurringScope, Mail, Compose, Today, Accounts, MailDark.

## Safety rules (the user's real Google accounts)

1. **No live Google calls during development.** There are no credentials yet. Everything runs against fixtures:
   unit tests use `StubURLProtocol` / `FixtureGoogle`; the app and smoke run with `THUBAN_DESK_FIXTURES=1`
   (in-process fake Google seeded from `SampleData`; the fixture session refuses every non-Google host).
2. **The send path** (`MailStore.send`, `GoogleClient.send`, `drafts.send`) requires a `Confirmed` token, which only
   `ConfirmWriteSheet` can mint (via `ConfirmRequest.run()`). Never call `run()` yourself, never send from tests or
   smoke. Fixture mode also disables sending in the `WriteGate` and `FixtureGoogle` answers 403 to any send.
3. **Irreversible actions confirm**: delete event (`CalendarStore.delete(…, confirmed:)`), delete forever / empty
   trash (`MailStore.deleteForever` / `emptyTrash`), sign out (`AppModel.removeAccount`). Reversible mailbox actions
   (archive, read/unread, star, spam, trash/untrash, labels) run immediately and optimistically, like Gmail.
4. `app.settings.writesEnabled` gates every write (`WriteGate`); sending additionally needs non-fixture mode.
5. **Live check** (later, by the user only): `scripts/live_check.sh "<calendar>"` creates one labelled test event,
   reads it back, deletes it, confirms deletion. It refuses to run without its env confirmation. Never run it.
6. No Keychain: tokens live in `~/Library/Application Support/Thuban Desk/credentials.json` (mode 0600;
   `THUBAN_DESK_HOME` overrides the whole home). Fixture mode never touches that folder: without
   `THUBAN_DESK_HOME` it uses a throwaway temp home (`AppPaths.home`), so the fake Google cannot disconnect real
   accounts.
7. Outgoing headers are single-line: `HeaderValue.singleLine` strips CR/LF from subject, names, addresses,
   In-Reply-To / References and filenames (`MIMEBuilder`), and `RFC2047.decode` never yields line breaks.
8. Only idempotent requests are retried after a 5xx (`GoogleRequest.isIdempotent`): inserts / creates and sends
   are retried on 429 only, so an ambiguous failure never creates a duplicate.
9. Scopes include `https://mail.google.com/` (needed by Delete forever / Empty Trash); an account linked without it
   gets "sign in again" instead of a bare 403.

| --- | --- | --- |
| Calendar | `Views/Calendar/**`, `App/Stores/CalendarStore.swift`, `CalendarSmokeScenes.swift` | `App/Stores/CalendarStore+*.swift` |
| Mail + Compose | `Views/Mail/**`, `ThubanDesk/Web/**`, `App/Stores/MailStore.swift`, `MailSmokeScenes.swift` | `App/Stores/MailStore+*.swift` |
| Today + Settings/Accounts | `Views/Today/**`, `Views/Settings/**`, `TodaySmokeScenes.swift`, `SettingsSmokeScenes.swift` | `App/…+Today.swift` |

Shared files (`AppModel.swift`, `Shell/*`, `Components/*`, `Theme/*`, `Routes.swift`, `project.yml`, the core
package) belong to the lead. Need something there? Add it in an `extension` in a new file in your own folder
(e.g. `Views/Calendar/AppModel+Calendar.swift`), or — for core logic — add a new file in the core package with
tests. Do not rename or reorder existing shared API. New files are picked up automatically (the project is
regenerated on every build).

## Data flow and shared API

- `AppModel` (`@Environment(AppModel.self)`): `settings` (auto-persisted; `AppSettings` in core has lastArea,
  calendarViewMode, hiddenCalendars, calendarTints, weekStartsOnMonday, showDeclinedEvents, defaultCalendar,
  defaultSendAccount, mailListWidth, pins, loadRemoteImages, lastMailFolder, dismissedNeedsReply …), `theme`,
  `area` / `select(_:)`, `settingsPane` / `openSettings(_:)`, `searchText` (title bar), `searchFocusRequest`,
  `newItemRequest` (⌘N), `accounts` (primary first), `primaryAccount`, `activeAccounts`, `ownAddresses`,
  `client(for:)`, `clientConfig`, `saveClientConfig`, `addAccount(loginHint:)` / `signIn` / `cancelSignIn`,
  `removeAccount(_:confirmed:)`, `refreshAll()`, `isSyncing`, `lastSync`, `syncErrors`, `syncSummary`,
  `confirm(_ ConfirmRequest)`, `now()` (pinned in smoke), `zone` (New York in fixture mode), `cache`,
  `isFixtureMode`, and the two stores.
- `app.calendar: CalendarStore` — `calendars: [CalendarRef]` (key, entry, tint, isHidden, name, canWrite),
  `visibleCalendars`, `setHidden`, `setTint`, `defaultCalendar`, `visibleRange` (set it from your view),
  `ensureEvents(from:to:force:)` (cache per calendar-month on disk, loads + prefetches neighbour months),
  `events(from:to:) -> [AgendaEvent]` (visible, sorted; `AgendaEvent` = calendar key + event + tint),
  `pendingInvitations`, `revision`, `refresh()`; writes: `create`, `scopes(for:in:changingRecurrence:)`,
  `save(_ patch, to:in:scope:)` (fetches the master and runs the RecurrenceEditPlanner), `delete(…, confirmed:)`,
  `rsvp`, `findOrCreateCalendar`. Views draw instances (`singleEvents=true`); edits go through the master.
- `app.mail: MailStore` — `scope: MailScope` (folder + optional account; All inboxes = `MailScope()`),
  `filter` (All / Unread / Needs reply), `searchQuery` (Gmail `q=`), `labels`, `mergedLabels`, `threads`,
  `visibleThreads`, `unreadCount`, `unreadInbox(account:)`, `labelNames(for:)`, `selection`, `checked` (bulk),
  `open(_:)` (marks read), `thread(_:)`, `perform(_ MailAction, on:)` (optimistic), `isPinned`/`setPinned`,
  `applyLabel(named:to:)` / `removeLabel`, `filterSender`, `saveDraft` (autosave), `discardDraft`,
  `send(_:account:confirmed:)`, `deleteForever(_:confirmed:)`, `emptyTrash(account:confirmed:)`,
  `attachmentData`, `fromAddress(for:)`, `defaultSendAccount`, `needsReply` / `needsReplyThreads`,
  `dismissNeedsReply`, `filters`, `activeFilterCount`, `sendAs`.
- Compose: build `OutgoingMessage` with `MIMEBuilder.reply(to:from:replyAll:html:text:ownAddresses:)` /
  `forward(…)` (replies ALWAYS from the account the thread arrived in: `fromAddress(for: key.account)`), save
  drafts while typing, and send with `app.confirm(ConfirmRequest(title: "Send this message?", …) { confirmed in
  try await app.mail.send(message, account:, confirmed: confirmed) })`.
- Mail HTML: `MailHTML.prepare(html:text:allowRemoteImages:css:inlineImages:)` → document for a WKWebView with
  JavaScript disabled, non-persistent data store, and a navigation delegate that opens links with
  `NSWorkspace.shared.open` (Mail engineer builds this in `ThubanDesk/Web`). Remote images blocked by CSP until
  "Load images" (or Settings default).
- Event descriptions: `HTMLSanitizer.richText(event.description)` → `Text(AttributedString)`; editor saves HTML.
- Recurrence editor: `RecurrenceBuilder(recurrence:start:zone:)` (nil → "Custom", leave untouched),
  `.summary`, `.recurrenceLines(isAllDay:zone:keeping:)`, `RecurrenceBuilder.suggestions(for:)`; "12 left":
  `RRule.occurrences(start:zone:…)` count after now. Scope sheet: `RecurrenceScope.title`, planner decides the calls.
- Today: `TodayAgenda.build(events:day:now:zone:)`, `TodayAgenda.durationText`, `app.mail.needsReplyThreads`
  (verdict.question = the asking sentence), `app.calendar.pendingInvitations`, RSVP via `app.calendar.rsvp`.
- Colours: calendars and labels are `CalendarTint` roles → `theme.color(for:)`, `theme.textColor(for:)`,
  `theme.softColor(for:)`. Never draw Google's hex.
- Cross-area links (lead, `App/DeskLinks.swift`): `DeskSearch.shared` (title-bar search → events via core
  `SearchMatch` + Gmail `q=` across accounts; Today/Settings show `SearchResultsView`, Mail a `SearchEventsStrip`,
  Calendar a `SearchMailPill`), `app.openEvent(_:)` (Calendar week + popover), `app.openInvitationEmail(for:)`,
  and in `AppModel+Today.swift` `requestReply` (opens the reply composer), `requestCompose`, `requestNewEvent`.
- Loading states: `Resource<T>` + `ResourceStateView` for single values; stores expose `isLoading` / errors.

## Design rules

Quiet, precise, the Thuban family. Colours ONLY from `theme` (`@Environment(\.thubanTheme)`): bg, panel, panel2,
line, line2, ink, inkDim, inkFaint, accent (fills), brassInkColor (accent text/icons), accentTint,
pos/neg/signal + Text + Soft. No literal hex in views (scheme swatches are the only exception). Fonts:
`ThubanFont.display` (serif titles), `.body`, `.small`, `.micro` (uppercase eyebrows), `.mono`. Radii: cards 10,
controls 8, chips 6. 1 px hairlines, no shadows except popovers per the design, no gradients, no emoji. Icons:
`Icon(.name)` — every line icon in the artboards is in `IconName` (verbatim SVG); add missing ones there.
Title bar is 52 pt (`ThubanMetrics.titleBarHeight`). Every control has an accessibility label; keyboard first.
Brass default, eight Atlas schemes + custom; Auto / Light / Dark.

## Build / test / smoke

- `DERIVED=.build/DerivedData-<you> scripts/build.sh` — use a private DerivedData when building in parallel.
- `scripts/test.sh` — core tests (fixtures and URLProtocol stubs only). Add tests for any core change.
- `DERIVED=… scripts/smoke.sh [out]` — Debug binary, temp home seeded with the sample accounts, fixture backend,
  clock pinned to Thu Sep 24 2026 2:40 PM (the artboards' moment), window 1440 × 900; walks `SmokeScenes.all`,
  writes PNGs, exits; only its own process is ever stopped. `SCENES=calendar` limits the walk. Register screens
  in your area's `…SmokeScenes.swift` (`SmokeScene(name, capture: .window/.sheet, settle:) { app in … }`); a scene
  may open a ConfirmWriteSheet (captured, then dismissed — never confirmed). Look at the PNGs against the artboards.
- `scripts/install.sh` — Release build to /Applications (lead only, after merges).
- `scripts/make_app_icon.sh` — static AppIcon from `AppArtSource.swift` (desk.svg verbatim); the dock icon is
  re-rendered live in the current theme by `AppIconRenderer`.

## iOS / iPadOS app (target `DeskiOS`)

Design boards: `~/.claude/jobs/bd9882f5/tmp/design/desk-ios/project/*.dc.html` — Today, Calendar Day / Month, Mail
inbox (mid-swipe), Mailboxes, Event editor, Change a repeating event, Thread, Reply sheet, Mail · Dark Brass (select
mode), iPad split view, Settings. Search has no board (house list style). Same safety rules as above; in addition
there are **no live runs at all** from development: the smoke uses only the in-process fake Google.

- **Target**: `DeskiOS` in the same `project.yml` — PRODUCT_NAME "Thuban Desk", bundle id `org.thuban.desk.ios`,
  iOS 18, iPhone + iPad, simulator builds unsigned (`CODE_SIGNING_ALLOWED=NO`). Sources: `DeskiOS/**` plus the
  shared app files listed in `project.yml` — `AppModel`, `Routes`, `ConfirmWrite`, `Resource`, `DeskLinks`, the two
  stores, `CalendarUIState` + `EventDraft` (editor, scope prompt, delete, RSVP flows), `TodayModel`,
  `ThemeEnvironment`, `Common`, `Icon`, `AppArt` + `AppArtSource`. Platform bits in shared files are fenced with
  `#if os(macOS)` (AppKit appearance + dock icon, loopback sign-in, `MailStore.compose`). Mac-only helpers with an
  iOS twin of the same name: `SmokeHarness`, `openThread` / `requestReply` / `requestCompose` / `requestNewEvent`
  (`DeskiOS/App/AppModel+Phone.swift`).
- **Core**: platforms `.macOS(.v15), .iOS(.v18)`. `LoopbackReceiver` and `GoogleSignIn.run` are macOS-only.
  iOS-relevant additions (all unit-tested): `GoogleMobileSignIn` / `GoogleMobileRedirect` (reversed client ID
  redirect `com.googleusercontent.apps.<id>:/oauth2redirect`, PKCE, no client secret, callback checks),
  `EventAlert` (the editor's Alert row ⇄ Google reminders), `RichRuns` (composer paragraphs/runs → HTML + text).
- **Sign-in on iOS**: `ASWebAuthenticationSession` (ephemeral) → `GoogleMobileSignIn`. The Google **iOS** OAuth
  client ID comes from `GOOGLE_IOS_CLIENT_ID` in `DeskiOS/Config/Secrets.xcconfig` (gitignored; see
  `DeskiOS/Config/DeskiOS.xcconfig` and `Secrets.example.xcconfig`, value = the part before
  `.apps.googleusercontent.com`). The build writes it to Info.plist `GoogleIOSClientID` and registers the reversed
  scheme in `CFBundleURLTypes` (iOS cannot register schemes at run time). Settings → Google sign-in accepts a pasted
  ID too and warns when this build does not register its scheme. Without an ID the app runs and says how to add one.
  Fixture mode disables sign-in.
- **Storage**: no Keychain. `credentials.json` in Application Support inside the app container, written with
  `NSFileProtectionComplete`; the whole app home folder carries the same protection class.
- **UI structure** (`DeskiOS/`): `App/` (entry + `RootView`, `PhoneRouter` — tab, per-tab paths, sheets, select
  mode, iPad section — `MobileAuth`, `LocalNotifications`, `SmokeHarness`), `Components/` (`PhoneStyle`: fonts as
  Dynamic Type styles, `InsetCard`, `PhoneRow`, `PhoneSegmented`, `PhoneSearchField`, nav buttons, chips, avatars;
  `PhoneScreen`: 44 pt nav row + 34 pt serif large title that collapses inline; `ConfirmSheet` + `confirmHost`),
  `Today/`, `Calendar/` (tab, week strip, time grid with now line, month + agenda, editor sheet, scope action sheet,
  calendars sheet), `Mail/` (Mailboxes, inbox with swipe + select mode, thread with `MailBodyView` WKWebView fed by
  core `MailHTML`, compose sheet + `PhoneComposeModel` + rich text view, label picker), `Search/`, `Settings/`,
  `IPad/` (sidebar + list + thread; the sidebar slides in below 1000 pt width). Custom tab bar (panel, hairline,
  brass selection) instead of the system one; system nav bars are hidden (swipe-back re-enabled).
- **Send**: the compose sheet's Send opens `ConfirmSheet` (only its button calls `ConfirmRequest.run()`); fixture
  mode refuses sends in the `WriteGate` and in `FixtureGoogle`; the smoke fails if a send endpoint was hit.
- **Notifications**: local only (event reminders 10 min before, new invitations, new needs-a-reply), never in
  fixture mode. No widgets, Live Activities or push.
- **Icon**: `scripts/make_ios_icon.sh` → one 1024 px opaque icon (Brass on the dark plate) from the same art
  (`scripts/make_app_icon.swift --ios`).

### iOS scripts

- `scripts/ios_build.sh` — simulator build into `.build/DerivedData-iOS` (`CONFIG=Release` for Release).
- `scripts/ios_smoke.sh [out]` — boots its own simulators "Thuban Desk Smoke" (iPhone 17 / iOS 26.5) and "Thuban
  Desk Smoke iPad" (iPad Pro 13-inch; a headless simulator cannot rotate, and its portrait width already gets the
  three-column layout), launches with `SIMCTL_CHILD_THUBAN_DESK_FIXTURES=1`, `…_SMOKE=1`, `…_NOW=2026-09-24T14:40…`,
  and screenshots every scene with `xcrun simctl io <udid> screenshot` into `.build/ios-smoke` (handshake through
  `Documents/smoke/state.txt` / `ack.txt` in the app container). `SCENES=mail,pad` limits, `IPAD=0` skips iPad,
  `KEEP_BOOTED=1` leaves the simulators running. Scenes live in `DeskiOS/App/SmokeHarness.swift`.
- `scripts/ios_install.sh` — Release simulator build installed into "Thuban iPhone" (created when missing); plus a
  signed device build + `devicectl` install only when a paired iPhone exists and `DEVELOPMENT_TEAM` is set.
